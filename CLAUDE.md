# CLAUDE.md

`docs/scope.md` is the source of truth for this project; read it before starting any work and follow it over anything here or in your own assumptions. The developer works entirely from an iPad through GitHub Codespaces and Claude Code cloud sessions, so they cannot run desktop apps (no Blender, QGIS, or local viewers); every step must run headless from the `Makefile` or a Python script, and previews happen only through the Codespace's forwarded port 8000 (`make serve`) or the GitHub Pages deploy of `main`. web/index.html always references ./dist/ and ./renders/; local serve and Pages use the identical site/ layout (both built by `make site`). Always keep `dist/base.glb` under 25 MB and the whole `dist/` directory under 60 MB (`make build` checks this), and never require a local GPU for building, rendering, or testing.

Renders are named `renders/NN-slug_YYYY-MM-DD.png`: `NN` is the camera number (01–20), `slug` is the camera name from `cameras.json` slugified (lowercase, hyphens), and the date is the data date, defined as `max(last_checked)` in `data/proposals.csv` at render time (not the day the render was made). `make renders-check` parses that date from each filename and flags any render older than the current data date.
