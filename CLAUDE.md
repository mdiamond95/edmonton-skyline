# CLAUDE.md

`docs/scope.md` is the source of truth for this project; read it before starting any work and follow it over anything here or in your own assumptions. The developer works entirely from an iPad through GitHub Codespaces and Claude Code cloud sessions, so they cannot run desktop apps (no Blender, QGIS, or local viewers); every step must run headless from the `Makefile` or a Python script, and previews happen only through the Codespace's forwarded port 8000 (`make serve`, then open `/web/`) or the GitHub Pages deploy of `main` (where `web/` is the site root, so asset paths must resolve both locally and on Pages). Always keep `dist/base.glb` under 25 MB and the whole `dist/` directory under 60 MB (`make build` checks this), and never require a local GPU for building, rendering, or testing.
